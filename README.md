# Ejemplo de sitio web

Este repositorio contiene un ejemplo sencillo de una web moderna con HTML, CSS y JavaScript.

## Archivos

- `index.html`: estructura principal de la página
- `styles.css`: estilos visuales del sitio
- `script.js`: script mínimo para actualizar el año del footer

## Cómo abrirlo

Puedes abrir `index.html` directamente en el navegador o servirlo localmente con un servidor estático.

Ejemplo:

```bash
python -m http.server 8000
```

Luego visita `http://localhost:8000`.

## Objetivo

Demostrar un repositorio base para una web de presentación o landing page.
